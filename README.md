# BloomNest Static Showcase

Create a modern, responsive static website called “BloomNest” for flowers, plants, and gardening. Use a soft botanical design with sage green, soft pink, cream, and light yellow, elegant fonts, rounded cards, subtle shadows, smooth animations, hover effects, and natural imagery.

Include Home, Flowers, Plants, Gardening Tips, Seasons, Gallery, and About sections. Add a hero with “Bring Nature Into Your Space” and an Explore Flowers button. Show flower cards for Rose, Sunflower, Tulip, Hibiscus, Orchid, and Lavender; plant categories with basic care information; beginner-friendly gardening tips; seasonal flower guides; and a beautiful masonry-style garden gallery.

Keep it fully static, mobile-friendly, clean, visually rich, and suitable for a professional portfolio. No login, database, backend, or complex functionality.
